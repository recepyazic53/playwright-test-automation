# Jet Kasko senaryoları

Jet Kasko iş senaryoları TEST ve CANLI için ortak spec dosyalarında tutulur. Ortam verileri platform veritabanından (Nöbetçi; eski `jet-kasko` verisi) yüklenir.

Mevcut teklif senaryosunun beklenen sonucu: `Teklif talebiniz için bölge müdürlüğünüz ile görüşünüz` mesajının görünmesidir.
